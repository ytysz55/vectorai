# SPIKE-020 — Windows E7 real-browser local smoke

- **Date:** 2026-09-25
- **Environment:** Windows x86-64, local Chrome 154.0.8037.57 (headless), Playwright 1.63.0 used only in an ignored local test directory, resvg 0.47.0 local executable, Vite loopback port 5173 and FastAPI loopback port 8000. Source was a generated 24 × 12 PNG of two flat colors; no user image or cloud service was used.
- **Procedure:** Start local API/Vite in separate processes, submit the PNG through the browser in `geometric` mode, await a published `success` job, render inline validated SVG, load stage evidence and multicolor overlay, select `face-1` with an actual pointer click, zoom to 200%, add a same-size local PNG as the optional baseline and compare all three panes' `viewBox` values. Kill both owned local server processes after the run.
- **Observed:** The job completed `success`; 36 canonical graph edges were rendered in each active pane. The selected entity was `face-1`. All three `viewBox` values were `6 3 12 6`; stage evidence rendered two measured cards (palette color SSE and renderer seam observation). Visual screenshot: ignored local `out/e7-browser-ui.png`; it was visually inspected, showing raster, actual SVG and user-provided baseline aligned at 200%.
- **Limitations:** This is one Windows browser smoke, **not** a cross-browser/cross-platform E6 renderer-parity gate, a pixelwise residual claim, a calibrated confidence claim, an accessibility/keyboard audit, or an automated CI E7 UI-006 suite. It did not exercise cancellation, `faithful`, `minimal`, or stroke modes in-browser. The source was tiny and procedurally generated. The Playwright binary is an opt-in local verification tool, not a pinned product dependency. Native CTest and Linux renderer/security gates remain outstanding.

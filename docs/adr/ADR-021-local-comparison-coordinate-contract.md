# ADR-021 — Aligned local comparison and inline SVG gate

- **Status:** Accepted for E7 UI-002
- **Context:** A resvg `preview.png` is not an SVG geometry view. Side-by-side review needs synchronized source and true output SVG coordinates; a third-party comparison must not be mistaken for topology certification.
- **Decision:** Load the selected raster's browser-reported natural pixel dimensions, then use one bounded source-pixel `viewBox` and shared pan/zoom state for three `<svg><image>` panes. The second pane loads `/v1/jobs/{id}/preview.svg`, not a PNG or PDF. This image-only API route requires a published E7 state and the same symlink/path guard as artifact downloads; legacy demo jobs cannot use it. The response is inline SVG with CSP `sandbox; default-src 'none'; img-src 'none'; style-src 'none'` and `nosniff`. For the optional local PNG/JPEG baseline, require ≤32 MiB and exact source-pixel dimensions; never upload it. Also fail closed on mismatched SVG intrinsic dimensions rather than stretching geometry to fit. Aspect-ratio letterboxing, cursor-anchor zoom, pan and bounds are computed in source-pixel units independently of pane CSS size.
- **Consequences:** A selected baseline is **user-supplied visual context, not a pinned external baseline or benchmark result**. Browser source orientation/color/alpha rendering and malicious-image behavior have not been cross-renderer certified here; the E6 gate and validated SVG remain authoritative. No real-browser screenshot/E2E has been run in the current environment. Server-side status records and artifact hashes remain the publication evidence; CSS/view state does not change the SVG. Cross-session view persistence and automatic external baseline rendering are deferred.
- **Evidence:** `apps/web/tests/comparison.test.mjs` covers mapping under zoom, pan and letterboxing; `python/tests/test_job_api.py` and `test_local_api.py` cover inline publication/symlink/legacy restrictions. Full Python suite, TypeScript build and web unit suite are separate release checks.

**Evidence update (2026-09-25):** One Windows/Chrome real-browser local smoke now exists; see [`SPIKE-020`](../spikes/SPIKE-020-e7-browser-smoke.md). The earlier no-browser statement reflects the decision-time state. This single test does not establish browser-matrix parity or complete UI-006 automation.

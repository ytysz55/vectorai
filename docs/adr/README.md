# Architecture Decision Records

ADR files are immutable decision history. A superseded decision remains in place and links to the replacing ADR.

Each ADR contains:

- status,
- context,
- decision,
- considered alternatives,
- consequences,
- validation evidence,
- review trigger.

Statuses: `Proposed`, `Accepted`, `Superseded`, `Rejected`.

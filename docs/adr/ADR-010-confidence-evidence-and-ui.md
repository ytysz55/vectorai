# ADR-010 — Stage evidence before confidence calibration

- **Status:** Accepted for E7 UI-004; calibration remains open.
- **Context:** The UI must explain why a job needs review without disguising model scores as probabilities. Existing engine outputs mix measured residuals (color SSE; rendered candidate premultiplied RGBA RMSE; seam gaps), heuristic margins (junction, stroke routing and arbitration), validation gates and fallback events. No pilot calibration, reliability diagram or expected calibration error (ECE) exists. A generic `confidence: 0.9` would mislead users.
- **Decision:** For published local jobs only, read the existing allowlisted `scene.json`, `run-manifest.json` and `validation-report.json`, each under an 8 MiB streamed byte cap. Stage cards label **measured residual**, **uncalibrated heuristic**, **validation gate**, or **safe fallback**. Explicit engine review signals identify the stage: junction `requires_review`, routing `ambiguous`, stroke arbitration `needs_review`, optimizer degraded fallback, nonzero renderer transparent-gap observation, or failed soft validation gate. An unrecorded stage is `not measured`, never assumed high confidence. A `needs_review`/`degraded` result without matching evidence is attributed only to job status, not a fabricated stage. No arbitrary UI threshold on RMSE, SSE or decision margins; no percentage probability and no residual heatmap claim. Structural hard gates remain authoritative regardless of fidelity.
- **Boundaries:** Numeric candidate scores and error rates must be finite and within the source metric's domain; missing/malformed data is not promoted to a favorable signal. The UI shows only fixed text and bounded numeric/code fields. It does not log source paths or upload images elsewhere. Stage evidence is a **job-level explanation**, not a calibrated per-entity uncertainty map. Optimizer render-rank RMSE is measured across pinned scales/backgrounds, whereas stroke candidate RMSE uses its own renderer comparison; the values must not be conflated. Palette weighted color SSE is not image RMSE. Renderer seam-gap rate is an observation and a seam-cover stroke is not canonical geometry.
- **Alternatives:** Averaging unrelated scores into one percentage (rejected); estimating confidence from mere success status (rejected); calculating browser-canvas residuals as if they were the certified E6 renderer metric (rejected); sending images to a cloud model (rejected).
- **Consequences:** Geometric mode can lack a measured rendered-image residual; the interface says so. Older completed jobs may have no optional scene evidence. No engine/default benchmark artifact schema is changed. Calibration of `high/medium/low`, per-entity evidence and pilot ECE are deferred to the E8 corpus and require an explicit versioned mapping before claiming probabilities.
- **Evidence:** `apps/web/src/evidence.ts` and `apps/web/tests/evidence.test.mjs`; the existing engine stage evidence remains source-of-truth. Full web build and Python suite continue to gate integration.
- **Review trigger:** Pilot-labeled confidence data, any changed renderer metric semantics, support for probability claims, or new edit/reprocess stages.

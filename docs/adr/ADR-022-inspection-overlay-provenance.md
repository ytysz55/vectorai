# ADR-022 — Job-scoped inspection geometry, not export topology

- **Status:** Accepted for E7 UI-003
- **Context:** `scene.json` previously held counts and seam pair IDs, not selectable coordinates. SVG face IDs are available, but a presentation-only seam-cover stroke cannot stand in for a canonical boundary, and smoothing/optimization can change the relationship between original graph edges and final exported path segments.
- **Decision:** Only E7 multicolor jobs opt into `inspection_overlay` in `scene.json`. The default engine/benchmark run remains unchanged; G2/G4 output and semantic-digest policies do not acquire an inspection payload. Face IDs are existing graph face IDs, selected scene vertices have stable **job-scoped** `face-{id}-cycle-{index}-node-{index}` IDs, and shared edge IDs use `CanonicalBoundarySegment.canonical_edge` (`edge-{id}`), with the same two owning face IDs and raw grid endpoints. Exclude exterior edges and presentation seam strokes. Regions are selected-scene contour polygons, not a replacement for exported SVG geometry. Node anchors can be prefit; graph edges are pre-simplification **evidence** and must not be marketed as the exact exported Bézier/stroke path. Overlay serialization never participates in topology validation or algorithm selection.
- **Resource and trust boundary:** If more than 2,000 scene vertices or 4,000 shared edges are needed, omit the *entire* overlay with a typed `OVERLAY_BUDGET_EXCEEDED` reason rather than display a partial misleading selection. The UI fetches the allowlisted, already-published local `scene.json` with an 8 MiB response cap, validates finite in-bounds geometry, IDs, face links and point counts, then renders in source coordinates on all panes. It does not parse or inject arbitrary SVG markup. Stroke jobs do not yet emit this multicolor overlay. A page opened on an older job simply cannot display the overlay; it does not reprocess the job.
- **Consequences:** Stable within one job, **not** globally stable across independent reruns, modes, edits, or face-ID renumbering. Model polygons and raw canonical graph segments may differ visibly from an optimized SVG; that distinction is explicit in UI/docs. Automatic linked selection in the exported SVG DOM and stroke-skeleton overlays are future work. Browser visual E2E and Linux renderer parity are not claimed.
- **Evidence:** `python/tests/test_scene_overlay.py`, E7 HTTP job/mode tests and `apps/web/tests/overlay.test.mjs`, plus full Python/TypeScript build gates.
- **Review trigger:** Scene schema version change, editable region reassignment, stroke overlay, or request for exact exported-segment-to-canonical-edge provenance.
